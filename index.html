Ψευδογλώσσα Interpreter

Ένα μοντέρνο, web-based περιβάλλον για την εκτέλεση και αποσφαλμάτωση κώδικα Ψευδογλώσσας (ΕΑΠ). Minimal σχεδιασμός, Dark Mode και άμεση εκτέλεση στον browser.

Άνοιγμα Compiler & Debugger GitHub Repo

⚡ Άμεση Εκτέλεση & Editor

Συντάκτης CodeMirror με αυτόματη συμπλήρωση (autocomplete), σύνταξη ΕΑΠ και προστασία από ατέρμονους βρόχους.

🐞 Step-by-Step Debugger

Βήμα-προς-βήμα εκτέλεση εντολών με οπτική επισήμανση της ενεργής γραμμής και ρύθμιση ταχύτητας.

🔍 Επιθεωρητής Μνήμης (Inspector)

Παρακολούθηση τιμών απλών μεταβλητών και οπτικοποίηση μονοδιάστατων και 2D πινάκων σε πραγματικό χρόνο.

📊 Πίνακας Τιμών (Trace Table)

Αυτόματη παραγωγή του πίνακα τιμών για ασκήσεις και εξετάσεις, με δυνατότητα εξαγωγής σε Markdown.
